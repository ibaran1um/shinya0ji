# 深夜0時の朝礼

夜行性のコウモリが、うっかり人間の会社に昼間出社してしまうバカゲー。
日なたにいると眠くなるので、日陰を伝って一番奥の自分の席まで帰りましょう。全4フロア。

ゲームプレイ：https://ibaran1um.github.io/shinya0ji

## 操作
- PC：WASD / 矢印キーで移動、Esc で一時停止
- スマホ：行きたい場所を指で押しっぱなし

## 公開（GitHub Pages）
1. このフォルダの中身（index.html, README.md）をリポジトリ直下に置く
2. Settings → Pages → Branch を main / (root) にして保存

## 結果のポスト
結果画面の「結果をポストする」から画像付きでXに投稿できます。
タグは index.html 内の `HASHTAG` で変更できます（初期値：深夜0時の朝礼）。
